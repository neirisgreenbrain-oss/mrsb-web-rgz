# Сайт ПАО «Мордовэнергосбыт» (MRSB)

Учебный сайт, выполненный в рамках расчётно-графического задания по дисциплине
«WEB-программирование». Сайт посвящён компании, определённой по индивидуальному
варианту, — **ПАО «Мордовская энергосбытовая компания»** (тикер MRSB).

## Хостинг
Сайт опубликован через GitHub Pages:
**https://neirisgreenbrain-oss.github.io/mrsb-web-rgz/**

## Страницы
- `index.html` — О компании;
- `news.html` — Новости;
- `currency.html` — Курс валют (калькулятор RUB ⇄ RON и диаграмма курса);
- `contacts.html` — Контактные данные с картой;
- `video.html` — Видео.

## Технологии
HTML5, CSS3, JavaScript (vanilla), библиотека Chart.js для диаграммы,
данные о курсе валют — сервис cbr-xml-daily.ru.

Меню реализовано по варианту 5 (иконка-«бутерброд» справа вверху),
валюта по варианту — румынский лей (RON).
